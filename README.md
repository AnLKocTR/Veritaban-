# Veritabanı

Eclipse ile geliştirilmiş Java ve MySQL örnek projesi.

## Gereksinimler

- JDK 25
- MySQL Server
- MySQL Connector/J 9.x

Eclipse'te projeyi içe aktardıktan sonra MySQL Connector/J JAR dosyasını Java Build Path'e ekleyin. `OgrenciEkle` örneği `localhost:3306/java_kursu` veritabanına bağlanır ve parolayı çalışırken sorar. Veritabanında `ogrenciler` tablosu bulunmalıdır.

Derleme çıktısı `bin/` klasörüne gider ve Git dışında tutulur.
